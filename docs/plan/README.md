# 기능 추가 고려 사항
## 공통
- 주문시 요청 사항을 입력할 수 있는 기능 추가
- 주문시 결제 수단 선택 기능 추가 (온라인/오프라인)
- 쿠폰 사용 기능 추가 //@ms 개좋아보임
  - 쿠폰 코드 입력 시 할인 적용 및 무료 메뉴 제공
- 디바이스, IP, 쿠키 기반으로 사용자 이력 관리
  - 재방문 확인 목적 및 사용자 맞춤형 추천 메뉴 제공

## 사용자
- 장바구니 기능 추가 //@ms 자리별 주문이라 1인 1주문일텐데 필요한 기능일지? 추후 안주가 들어온다면 이야기가 달라지겠지만, 우리는 안주 콜키지가 가능
- 메뉴별로 태그 라벨 기능 추가 (예: #상남자, #추천, #인기, #달콤 등) // @ms 현재 가능할건데 한번 확인이 필요해보임
- 사용자 주문내역 확인 기능 추가
  - 사용자 주문내역 확인 시, 주문한 메뉴, 결제 수단, 결제 금액, 주문 시간 등 확인 가능
- 외국인 손님을 위한 다국어 지원 기능 추가 (영어, 중국어, 일본어 등)
- 오프라인 결제 완료 시 포스 ->  주문내역에 결제 완료 상태 반영 기능 추가 (웹훅)

## 관리자
- 결제 수단별 통계 기능 추가 (온라인/오프라인 결제 비율 확인)
- TOSS 포스 테이블 연동 기능 추가 (TOSS 포스 SDK 설치 필요함)
  - 실제 매장 테이블 정보를 TOSS 포스와 연동
  - 테이블 정보에 따른 사용자 입장 QR코드 생성 및 사용 관리
  - TOSS 포스에서 보이듯이, 테이블별 주문 내역 확인 가능
- 상품마다 레시피 정보 추가 (재료, 조리법 등)
