# lam

Monorepo for the `lam` QR menu project.

## Structure

- `lam-web`: mobile-first QR menu frontend built with Next.js 16 and React 19
- `lam-api`: Go API scaffold for menu and store-facing services

## Quick Start

### Web

```bash
cd lam-web
npm install
npm run dev
```

### API

```bash
cd lam-api
go run ./cmd/server
```
